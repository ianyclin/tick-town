# 時鐘遊戲設計草案（暫名：滴答小鎮）

給小一到小三練「看時鐘、撥時鐘、算時間」的遊戲。跟九九流星隊同一套做法：孩子只覺得在玩，遊戲在背後追蹤哪裡不會、多出那一種題。

## 0. 給孩子的設計原則（先讀這段）

九九流星隊的玩家是小三，而且練的是「已經會的東西」；時鐘的玩家從**小一**開始，很多是「還不太會」。所以：

1. **先有故事，再有題目。** 不出現「撥到 3:45」這種指令。是小鎮的動物有事要做：「小熊 3 點半要去公園，幫牠把鐘撥好」。每一題都是幫誰做一件事，撥好了那隻動物就真的出門。
2. **圖多字少。** 時刻用「太陽在哪、動物在做什麼」表現；指令一句話、大字；等級 1 幾乎不用認字也能玩（圖＋數字鐘）。
3. **用手撥，不用打字。** 主角是**拖指針**。指針末端有大大的圓把手（≥ 56px），拖的時候每 5 分「咔」一聲並吸附；孩子手不穩也不會撥到 3:47。打數字只在等級 2 以上的「讀鐘」才出現，而且先給三張卡片選，會了再打。
4. **時針是烏龜、分針是兔子。** 短針慢（烏龜）、長針快（兔子），針尖各有一個小臉；拖兔子時烏龜慢慢跟著走，孩子親眼看到「時針在兩個數字中間」。這一個比喻解掉最常見的兩種錯（搞反、分針指 4 讀成 4 分：兔子跑一格是 5 步）。
5. **先玩再考。** 有一個**自由玩**的鐘：隨便撥，小鎮跟著變（太陽移動、商店開門、路燈亮、動物去睡覺）。沒有題目、沒有對錯。孩子從這裡自己發現「撥到 12 點天最亮」「8 點大家都睡了」。
6. **沒有倒數、沒有扣血。** 等級 1、2 完全不計時；錯了只是動物歪頭「咦？」然後把正確位置亮給你看，再撥一次。慶祝要大（敲鐘、彩帶、動物跳舞），失敗要小。
7. **進度看得見、摸得到。** 答對點亮小鎮的一戶燈；一天的事都做完，小鎮入夜、滿鎮燈火。孩子在「蓋自己的小鎮」，不是在刷題。
8. **錯的種類比錯的題目重要。** 遊戲背後追蹤「哪一種錯」（第 1 節），提示動畫對症下藥，不是重複出同一題。

## 1. 錯誤類型（遊戲背後的東西，孩子看不到）

| 代號 | 錯法 | 例子 | 孩子看到的提示 |
|---|---|---|---|
| `hourLate` | 時針快到下一格就讀成下一個小時 | 2:50 讀成 3:50 | 烏龜說「我還沒走到 3 喔」，2 到 3 那段路亮起來 |
| `minIndex` | 把分針指的數字當分鐘 | 分針指 4 讀成 4 分 | 兔子從 12 開始一格跳 5 步：5、10、15、20 |
| `handSwap` | 時針、分針搞反 | 4:30 讀成 6:20 | 烏龜、兔子各自揮手：「短的是我」 |
| `halfHour` | 半點讀錯小時 | 3:30 讀成 4:30 | 烏龜停在 3 和 4 中間：「3 點半」 |
| `minOne` | 1 分的小格數錯 | 23 分讀成 22 分 | 放大兔子那一段，小格一格一格亮 |
| `carry` | 經過時間跨整點算錯 | 2:40 過 35 分 | 時間軸分兩段：先到 3:00，再 15 分 |
| `ampm` | 上午、下午搞錯 | 下午 3 點寫成 3:00 | 太陽／月亮圖示：「下午 3 點＝15 點」 |
| `read12` | 12 點附近讀錯 | 12:05 讀成 1:05 | 烏龜指 12：「這是 12 點」 |

每種錯有權重（指數平滑，同九九的 `err`）；出題依孩子最弱的錯法挑**會誘發那種錯的時刻**（`hourLate` 弱就多出 x:50、x:55），孩子只覺得「怎麼又是小熊」。答錯的類型由答案自動判定（讀成下一個小時 → `hourLate`；答案 = 分針指的數字 → `minIndex`……判不出來 → `other`）。

## 2. 三個等級（設定頁三個大圖示按鈕，不寫年級）

| 等級 | 圖示 | 內容 | 課綱 |
|---|---|---|---|
| 1 | 太陽 | 整點、半點；指針鐘配數字鐘 | 一年級 N-1-6 |
| 2 | 兔子 | 幾點幾分（5 分 → 1 分）；撥鐘 | 二年級 N-2-13 |
| 3 | 時間軸 | 經過時間、幾點到幾點、上下午、24 小時 | 三年級 N-3-17 |

預設 2；等級 1 的孩子大人幫忙選一次就好。課綱條目來自教案引用，不是教育部原文，上架前再對一次。

## 3. 玩法

### 3.1 小鎮的一天（主角）
- 小鎮有 6～8 隻動物，每天各有一件事（起床、上學、吃午餐、去公園、洗澡、睡覺），事件的時刻每天隨機、依等級取整點／半點／5 分／1 分。
- 畫面：上面是小鎮（動物在家門口等），中間一座大鐘，下面是「現在要幫誰」的卡片（動物的臉＋一句話＋數字鐘或文字時刻）。
- 孩子拖指針撥到那個時刻 → 鐘樓敲鐘，那隻動物出門去做事，牠家的燈亮一盞。
- 全部做完 → 天黑、滿鎮燈火、放煙火，這一天完成（= 每日任務的一項）。
- 撥錯：動物歪頭「咦？」，正確位置用虛線指針亮出來，再撥一次就好；這天還是會完成，只是燈的顏色不一樣（不說「失敗」）。
- 等級 3 時卡片會說「小熊 2:40 出門，走了 35 分鐘，幾點到公園？」撥到到達的時刻；跨整點時時間軸動畫分兩段。

### 3.2 自由玩的鐘
- 主選單直接有一座鐘，隨便撥。太陽、月亮、商店、路燈、動物作息全部跟著時刻變；撥到整點敲鐘。
- 不記錄、不出題。等級 1 的孩子可能大半時間都在這裡，這是刻意的。

### 3.3 幾點了？（讀鐘）
- 看大鐘，**先選卡片**：三張數字鐘卡片選一張（等級 1、2 前段）；熟了（該時刻已點亮）才出現鍵盤打數字。
- 可以選擇跟自己比時間（像幽靈競速），預設關閉，大人在設定打開。

### 3.4 配對（翻牌）
- 8～12 張牌：指針鐘、數字鐘、「三點半」文字、動物作息圖（吃午餐 = 12:00）混在一起，翻到一樣的就留下。
- 沒有時間限制；翻錯就翻回去。

### 3.5 兩個人一起（雙人）
- 上下分割，各自撥鐘，先撥對的拉一格；可選機器人。程式沿用拔河（`touch-action`、繩子變滑、機器人速度跟著孩子）。
- 大人加難：大人那邊出經過時間、24 小時制。

## 4. 鐘面（最重要的元件）
- 大：直徑 ≥ 70vw；數字 1～12 用大圓字；每 5 分一個粗刻度、每分一個細刻度（等級 1 只畫粗的）。
- 指針：時針短粗藍色（烏龜臉）、分針長細紅色（兔子臉）；末端把手 ≥ 56px 可拖。
- 拖分針：每 5 分吸附（等級 3 才 1 分），吸附時「咔」；時針同步跟著走（分針轉一圈時針走一格）。
- 拖時針：分針不動；只允許停在整點／半點／當前分針對應的位置，不會出現「時針指 3 分針指 6」這種不存在的時刻。
- 撥到目標：鐘面發光一下、敲鐘。
- 讀鐘題用同一個元件（關掉拖）。星圖也用它（第 5 節）。

## 5. 星圖 → 鐘面星圖
- 一個大鐘面，12 格（小時）× 12 格（5 分）排成同心環；等級 1 只亮整點、半點那兩圈。
- 顏色同九九：還沒遇過、熟悉中、容易錯、已點亮。
- 下面說明框用孩子的話：「兔子跑到 10 以後，你常常會把烏龜看成下一格。多撥幾次就會了！」，給大人看的細節再點開。

## 6. 存檔
```js
DB = {
  facts: { 's:3:45': {n, err, t, w}, 'r:2:50': {...}, 'e:...' },   // s 撥鐘、r 讀鐘、e 經過時間；鍵 = 題型:時:分
  errs: { hourLate, minIndex, handSwap, halfHour, minOne, carry, ampm, read12 },   // 錯法權重
  best, set: { lang, music, sound, level, timer }, daily, pet, retest, town: { lit: [...] }
}
```
- `record(k, ok, ms, errType)`；熟練判定沿用九九（`n ≥ 3`、`err < 0.12`、想出答案 ≤ 4 秒，撥鐘要拖所以放寬），等級 1 不看時間。

## 7. 直接沿用（複製程式，不做共用程式庫）
- 兒童規範：家長關卡（含三次錯 30 秒）、不收個資、不連網、無廣告。
- App 版解鎖、試玩 3 次、購買卡與鎖卡的文字規則（孩子看到的不提價錢、不叫孩子去叫大人買）。
- 三語 `STR`／`tx()`、切字腳本、`data-t`；多人、備份（新 key：`tick-town-v1`、`tick-town-who`）。
- 每日任務、徽章、寵物（**換成鐘樓的動物**：貓頭鷹／松鼠／小熊，新圖；照顧、愛心、換徽章整套搬）。
- Capacitor 外殼、自動建 APK、商店文案與截圖工具、版面規則（44px、三語等寬、安全區、iPad 放大）。

不沿用：連擊倍率、一擊即死、魔王、落地扣心（時鐘不做速度壓力）。

## 8. 畫面風格
- 白天小鎮：天空淡藍到米白、遠山綠、暖色屋頂、中間鐘樓；太陽位置跟著時刻（早上左、中午頂、下午右），晚上換月亮與路燈。
- 主色：鐘面米白、時針藍、分針紅、強調橘黃；圓角、粗線條、大圖示。
- 字型沿用 Lilita One（數字）、Chiron、Zen Maru；音樂音效 Web Audio 合成，加敲鐘聲。
- 動物圖、鐘樓圖：AI 生成＋切圖流程同寵物（著作權同樣的注意事項）。

## 10. 開發順序
1. 新 repo、CLAUDE.md（兒童規範、上架經驗、本文件）。
2. **鐘面元件**：拖指針、吸附、烏龜兔子、時針跟著走、放大小格。先做到孩子一拿就會。
3. 自由玩的鐘 + 小鎮會跟著變（第一個可以給孩子玩的版本，先看反應）。
4. 小鎮的一天 + 錯誤類型判定 + 提示動畫。
5. 幾點了、鐘面星圖、每日任務。
6. 配對、雙人、寵物、三語、App 版、商店文案。
