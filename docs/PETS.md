# 寵物的圖

2026-11 美術重做之後，寵物不再用切出來的 PNG，改成 `index.html` 裡自己畫的 SVG（`ART.pet(kind, st, wear)`）：

- 階段 0 是蛋（奶油色、斑點是那隻動物的顏色）；1 坐在蛋殼裡；2～4 同一隻越長越大（`PSC` 是縮放比例）；4 身邊有小星星。
- 三隻：貓頭鷹（淡紫）、松鼠（橘）、小熊（蜂蜜棕），畫法在 `ART` 的 `C`。
- 配件六樣（蝴蝶結 1、圍巾 2、墨鏡 4、帽子 6、星星髮夾 8、皇冠 12 個徽章）畫在 `G`，戴的位置在 `FIT`（每隻動物的頭頂、眼睛、脖子），跟著寵物一起縮放。
- 看樣子：`node tools/art-lab.cjs <輸出.png> pet-owl-0,pet-owl-1,pet-bear-4,g-hat`。

之後如果改用 ChatGPT 生成的軟陶插畫：用 `tools/cut-clay.py` 切到 `assets/clay/pet-<種類>-<階段>.webp`，把名字加進 `CLAY`，`petSVG()` 要另外寫用圖的版本（配件的位置要每張圖各量一次）。
